# Asset attribution

All runtime assets in this repository are either project-created or generated from the compatible
inputs recorded below. No asset has an unknown license.

## Project-created assets

Car-role pictograms and the family activity-book artwork are project-created procedural
geometry in `CarRoleGeometry.hpp`, distributed under MIT; no external icon or image sources.
The alpha-tested conifer needle motif is project-created at runtime by
`makeNeedleSprayImage` in `ProceduralMaterials.cpp` (MIT), with no external image input.

repository. CNA and sharp-runtime retain their own licenses.

## Onboard display and station-sign font

| Asset | Creator | Source | License | Modifications |
|---|---|---|---|---|
| Embedded antialiased ASCII coverage atlas and proportional metrics in `DisplayFontData.hpp` | Bitstream and DejaVu contributors | DejaVu Sans 2.37; https://dejavu-fonts.github.io/ ; generation input `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf` | Bitstream Vera permission notice; DejaVu changes public domain. Full notice: `assets/licenses/DejaVu.txt` | Rasterized ASCII 32–126 at 28 px into a 512 × 256 coverage atlas; lossless RLE; no TTF redistribution |

`tools/generate_display_font.py` regenerates the committed 58 KB header with Python/Pillow
(generation used Pillow 11.1.0). The input font SHA-256 is
`57f73e11f51999432bf7ab22ce55b6f945d5eca1bf824404cfa9ec2e3718c84e`.
Ordinary builds and runtime need neither Pillow nor an installed font. The generated subset
retains its font license rather than becoming MIT; that notice is included by the existing
asset installation rule. No Debian packaging files or GPL packaging code were copied.
Station names, platform identifiers and live departure boards reuse the same atlas;
no additional font data or runtime system-font dependency is introduced.

## Synthetic announcements

The committed `announcement_*.wav` files were created locally; neither the inference engine nor the
voice model is redistributed here.

voice license marked “All Rights Reserved,” so all clips produced during evaluation were
overwritten by the public-domain-source voice before delivery.
